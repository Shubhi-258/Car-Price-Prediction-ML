# Car Price Prediction Using Machine Learning

This project predicts the selling price of used cars using Machine Learning techniques. The model is trained on historical vehicle data containing features such as car age, fuel type, transmission type, owner count, and kilometers driven.

## Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering and visualization
* Linear Regression and Lasso Regression models
* Model evaluation and performance comparison

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab

## Dataset

The project uses the Cardekho Used Car Dataset available on Kaggle.

## Results

The trained model achieved approximately 87% accuracy in predicting used car prices.

## Learning Outcomes

* Data preprocessing and feature selection
* Regression model implementation
* Model evaluation using R² score
* Data visualization and analysis
* End-to-end Machine Learning workflow
